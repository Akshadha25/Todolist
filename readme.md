# To-Do List Application (Java Console)

## Overview
A simple console-based To-Do List application developed in Java.  
This project demonstrates object-oriented programming, file handling, and basic CRUD operations in Java.

## Features
- Add tasks with title, description, and due date.
- View all tasks.
- Mark tasks as completed.
- Delete tasks.
- Persistent storage using a file (`tasks.txt`).

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- File I/O (Object Serialization)
